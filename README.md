## Visitors counter

This is a project that we created as part of our activities in Data Science club, organized by Department of Artificial Intelligence Systems in Lviv Polytechnic National University.

The key idea was to track the visitors of a grocery store using recording from a surveliance camera. We addressed this problem by training the YOLOv8 small model on a dataset that can be found by [this link](https://www.kaggle.com/datasets/hoangxuanviet/scut-head).

Preview of the project page:We managed to achieve the following benchmarks on the test dataset:

mAP50-95 (Box): 0.5606842299395302
mAP50 (Box): 0.9542602816697466
Precision (Box): 0.9125328092235351
Recall (Box): 0.9068774142053332
